# Exotic-Greases
Elden Ring Mod. A collection of over 50 new greases made everlasting. Progress throughout the the Lands Between and the Shadow Realm to find them.
Description
A collection of over 50 new greases made everlasting. Progress throughout the the Lands Between and the Shadow Realm to find them. These greases last forever until death, spawn, teleport or un-equip.
This mod does not effect vanilla greases.
When you first go into the Stranded graveyard at the start you'll get a note . Follow the note and you'll find the exotic greases.
There's so much but i won't spoil much here. Enjoy discovering.

Installation instructions
Follow the Read First in the mod folder. Additionally there's an Extras folder for those who want to unlock the greases from the beginning

Main features
50 new greases themes around Elden Ring and some Dark Souls thematics with varying gameplay effects. 

Requirements
Mod engine 3 CLI installation from the requirements section.
